# acilkurye
istanbul da acil kuryelik ihtiyaçları için web site

## VS Code'daki `kuryesitesi` klasörünü bu depoya bağlama

Eğer web siteni VS Code içinde `kuryesitesi` klasöründe geliştirdiysen, aşağıdaki adımlarla bu depoya bağlayabilirsin.

### 1) Depoyu yerelde aç

```bash
cd /path/to/acilkurye
```

### 2) `kuryesitesi` içeriğini depoya kopyala

```bash
cp -r /path/to/kuryesitesi/* /path/to/acilkurye/
```

### 3) Git ile commit al

```bash
git add .
git commit -m "kuryesitesi web sitesi dosyalarını ekle"
```

### 4) Uzak depoya gönder

```bash
git push origin your-branch-name
```
